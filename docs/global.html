Methods

WUiLoginout(site, optopt) → {Object}

Description:

  • 前端界面用之使用者登入出輔助功能函數

    本套件為瀏覽器端工具(使用window、localStorage與內建fetch)，於Node僅可載入，呼叫需瀏覽器環境

    login、logout、detect之錯誤物件一律為{text,msg}，text為說明文字，msg之型別依情況而異: login之連線錯誤為字串(例'Error: Request failed with status code 500')；logout、detect之連線錯誤為Error物件(非2xx時帶status與response)； 流程中之非預期例外為原拋出值(text為'登入時發生例外'、'登出時發生例外'、'驗證令牌時發生例外')；其餘為字串代碼、伺服器回傳之msg或回應物件

    回呼拋錯之處置: 流程內回呼(login之afterGetUser、logout之procLogout、detect之procCheckToken)拋錯視為該流程失敗，錯誤包成{text,msg}後走錯誤通道； 結束通知回呼(afterLogin、loginSuccess、loginError、afterLogout、logoutSuccess、logoutError、detect之procLogout)拋錯不吞， login與logout以原拋出值reject，detect之procLogout於計時器內呼叫故成為未處理之rejection；結束通知被呼叫前，本套件之狀態變更皆已完成
